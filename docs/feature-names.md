# Feature names

Names users see, checked against craft-contrib
[standards/naming.md](https://github.com/storytold/craft-contrib/blob/main/standards/naming.md).

## Record

- **Date:** 2026-11-17 (skeleton and polish pass).
- **Sources checked:** the standard's names list (none of these names is in it), and the
  reference application's own feature names as observable in public product material (none of
  ours is one of them: the reference apps' coined names for completion, card boards and
  revision tools are not used; ours are plain descriptions).
- **Not run:** the trademark-register searches of rule 4 (USPTO, EUIPO, WIPO). All names below are
  ordinary descriptive words that many unrelated writing and screenwriting tools use for the same
  thing, so they are expected to be fine, but per rule 5 a Craft owner should confirm on the
  adoption pull request.
- **Decision:** use the names below. "FDX" and "Fountain" appear only as file format names.

| Name | Where | Note |
|---|---|---|
| Scene Navigator | View menu, left panel | Descriptive |
| Page Preview | View menu, toolbar | Descriptive |
| Export Scene List for Storyboards | File menu | Descriptive; names what it writes |
| Add Stable Scene IDs | Script menu | Descriptive |
| Title Page | Script menu | Screenwriting term |
| Index Cards | View menu, toolbar | Descriptive; the paper cards writers pin to a board |
| Focus Mode | View menu | Descriptive |
| Typewriter Scrolling | View menu | Descriptive |
| Dark Page | View menu | Descriptive |
| Reports | Script menu | Descriptive |
| Lock Scene Numbers, Start Next Revision, Mark Revisions, Clear Revision Marks | Production menu | Production terms used across the industry |
| Automatic (CONT'D) | Format menu | Screenwriting term |
| Check Spelling as You Type, Next Misspelling, Add Word to Dictionary | Edit menu | Descriptive |
| Element names (Scene Heading, Action, Character, Parenthetical, Dialogue, Transition, Shot, Centered, Lyric, Section, Synopsis, Note, Omitted Text, Page Break) | Format menu, toolbar | Standard screenwriting and Fountain terms |
