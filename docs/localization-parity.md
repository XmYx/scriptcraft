# Localization parity

ScriptCraft's interface goes through craft-libs' `craft-i18n` (`crates/ui-egui/src/i18n.rs`).
Every visible string is an English source text looked up with `tr`, `trf` (with `{name}`
placeholders), `trn` (plurals) or `tr_command` (command labels by `@id`). The catalogs are an
optional build input: `CRAFT_I18N_DIR=<craft-i18n checkout>` embeds every locale that has a
`scriptcraft.tsv`, `CRAFT_I18N_REQUIRED=1` makes a missing checkout a build error (releases), and
without it the app is English only. View ▸ Language switches the language; the default is the
system language when ScriptCraft offers it.

| | State |
|---|---|
| Interface strings through craft-i18n | done: menus, toolbar, status bar, navigator, dialogs, element names, hints, file dialogs, error and status messages |
| Source-string list | `i18n/source-strings.tsv`, 169 rows, generated by `cargo xtask strings`; CI fails when it is stale |
| Shared strings | 36 of them are already in craft-i18n's `common.tsv` (`cargo xtask strings --shared <checkout>`): All files, Author, Cancel, Character, Characters, Don't Save, Edit, File, Format, Help, Keyboard Shortcuts, Language, New, OK, Open…, Page {page} of {pages}, Paper, Redo, Save, Save As…, Saved, Title, Undo, Unsaved changes, Untitled, Version {version}, View, Zoom In, Zoom Out and others |
| `locales/<locale>/scriptcraft.tsv` in craft-i18n | **none yet**: a craft-i18n PR adds them; until then every language shows English |
| Offered languages | de, es, fr, hu, it, ja, ko, nl, pl, pt-br, sv, zh-hans, once their catalogs exist |
| Right-to-left languages | not offered: the script page is left-to-right by design; the interface needs a right-to-left check first |
| Plurals | `@plural` rows for scenes, pages and added scene ids |
| Not localized | the command-line tool's output (English, like the siblings' CLIs); operating-system error reasons inside messages; screenplay terms printed on the page (`(MORE)`, `(CONT'D)`), which follow the script, not the interface |
